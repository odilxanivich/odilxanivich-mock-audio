# Odilxanivich 1 Listening - TOEIC: recording script

Original material © Odilxanivich in Korea. **Keep this file private** (it contains every answer).

Build the four audio files with the same tool as before:

```bash
.venv/bin/python tools/make_audio.py toeic-1-listening-audio-script.md
```

This creates `toeic/odilxanivich-1-toeic-listening-section-1.mp3` … `-section-4.mp3` (parts 1–4) and a `.cues.json` next to each one.
Push the whole `toeic/` folder to the private audio repo. The cue files let the exam highlight the current question in sync with the recording.

Estimated length: Part 1 ≈ 2 min, Part 2 ≈ 7 min, Part 3 ≈ 17 min, Part 4 ≈ 12 min (40 min in total).
Tip: use `--bitrate 48k` to make the files smaller. Lines such as `[[Q7]]` are cue markers; do not delete them.
